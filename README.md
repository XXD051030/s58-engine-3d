# S58 直列六缸 3D 演示

BMW M4（G82/G83）S58 3.0 L 直列六缸双涡轮增压发动机的交互式 3D 透视演示。整个演示只有一个 HTML 文件，用 three.js 渲染。

作者：[@XXD](https://github.com/XXD051030)

## 打开方式

下载 `index.html`，用浏览器直接打开。需要联网，因为 three.js 和字体从 CDN 加载。

## 内容

- 曲轴、活塞、连杆、24 个气门（含气门弹簧、滚子摇臂、液压挺柱）、进排气凸轮轴、正时链、喷油器、火花塞、进气歧管与水冷中冷器、两台单涡管涡轮
- 四冲程循环按颜色区分：进气蓝、压缩紫、做功橙、排气灰；点火顺序 1-5-3-6-2-4
- Double-VANOS 凸轮相位随转速和负荷变化
- 转速 750–7200 rpm、油门 0–100% 可调；动画可放慢 5–1000 倍，也能暂停，或每次单步 10°
- 9 个预设视角；拖动旋转、滚轮缩放、右键平移；支持剖切视图、调节外壳不透明度和开关各图层
- 实时数据：扭矩、功率、增压、涡轮转速、VANOS 角度、点火提前角、峰值缸压
- 所选气缸的缸压与气门升程曲线，以及全负荷外特性曲线
- 合成的发动机声音

## 数据说明

以下为 G82 M4 Competition 的公开数据，三维尺寸按这些数据等比例建模：

- 功率 375 kW / 6250 rpm
- 扭矩 650 N·m / 2750–5500 rpm
- 缸径 × 行程 84 × 90 mm
- 压缩比 9.3:1

缸压、增压、VANOS、点火角等实时数据来自简化的物理模型，只用来演示变化趋势，不是厂家的标定值。涡轮朝向和管路走向也做了简化。
